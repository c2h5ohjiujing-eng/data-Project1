# 当代人工智能实验课——实验一：文本分类

## 一、实验简介

本项目为当代人工智能实验课实验一，主要完成新闻文本分类任务。

实验采用 TF-IDF 对文本进行特征表示，并使用 SVM 和 Logistic Regression 两种经典机器学习算法进行分类实验。

通过设置不同的 C 参数，在验证集上比较不同模型的分类效果，并根据验证集准确率选择最终模型。

## 二、实验环境

* Python 3.10.21
* NumPy
* Pandas
* Scikit-learn
* macOS

## 三、实验方法

实验主要流程如下：

1. 加载训练数据和测试数据；
2. 将训练数据划分为训练集和验证集；
3. 使用 TF-IDF 将文本转换为数值特征；
4. 分别训练 SVM 和 Logistic Regression；
5. 测试不同 C 参数；
6. 使用验证集准确率比较模型；
7. 选择最优模型；
8. 使用全部有标签训练数据重新训练；
9. 对测试集进行预测。

## 四、实验参数

TF-IDF 最大特征数量：

```text
5000
```

训练集与验证集比例：

```text
80% : 20%
```

随机种子：

```text
42
```

SVM：

```text
kernel = linear
C = 0.1, 1.0, 10.0
```

Logistic Regression：

```text
C = 0.1, 1.0, 10.0
max_iter = 1000
```

## 五、实验结果

| 模型                  |    C | 验证集准确率 |
| ------------------- | ---: | -----: |
| SVM                 |  0.1 | 81.48% |
| SVM                 |  1.0 | 90.23% |
| SVM                 | 10.0 | 90.64% |
| Logistic Regression |  0.1 | 84.33% |
| Logistic Regression |  1.0 | 89.76% |
| Logistic Regression | 10.0 | 91.18% |

在本次实验设置的参数范围内，Logistic Regression，C=10.0 的验证集准确率最高，为 91.18%。
